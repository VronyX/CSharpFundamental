Ketentuan:
• Input jumlah mata kuliah (1-8), lalu nama, SKS (1-4), dan nilai angka (0-100) 
tiap mata kuliah. Ulang input yang di luar batas.
• Nilai huruf: minimal 85 = A, 70 = B, 55 = C, 40 = D, di bawahnya E.

• Bobot memakai switch: A = 4, B = 3, C = 2, D = 1, E = 0.

• IPK = jumlah (bobot x SKS) dibagi total SKS, bertipe double.

• Predikat: IPK minimal 3,51 dan tidak ada nilai E = Cumlaude; minimal 3,01 = Sangat Memuaskan;
minimal 2,76 = Memuaskan; di bawahnya Cukup. Batas cumlaude ditulis sebagai const.

• Method minimal: KonversiHuruf(nilai), Bobot(huruf), HitungIpk(totalMutu, totalSks), 
Predikat(ipk, adaE), dan CetakTranskrip(...).
